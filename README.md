# rightnow-ai

A self-hosted alternative to Instantly.ai: cold-email campaigns, inbox warm-up, and a unified inbox, running on your own machine (Docker Compose) or a VPS. Same codebase in both modes.

## Quickstart

See [docs/ops/LOCAL.md](docs/ops/LOCAL.md).

## Development

```
npm ci
npm test
npm run lint
npm run typecheck
```
