## 2. Information architecture & navigation

App shell is four regions (1920px capture):
1. **Top bar** (full width, ~52px tall, very dark navy ~#0A1A33 (est.)). Left: four icon-only app switchers at x~32/79/126/173 (Inbox, Calendar, Contacts, Analytics) plus a kebab "more" (⋮). Active app gets a lighter rounded square highlight behind the icon. Center: global search pill (~530px wide, rounded, translucent lighter-navy fill, placeholder "Search Demo Inbox" i.e. scoped to current inbox, with a filter icon at the right end). Right: "Setup guide" text with a thin green progress underline and chevron, a gradient pill "Upgrade" (diamond icon, pale yellow-to-pink), settings gear, user avatar with initials "RM" (yellow circle, presence dot).
2. **Left sidebar** (~240px, light gray #F2F3F7 (est.)): primary blue "Compose" split button on top (blue ~#2F6FEB (est.), icon + label + dropdown caret segment), then collapsible groups with tiny uppercase-free labels and caret: "Me" (Inbox with children Assigned to me / Shared with me / Discussions; Starred; Drafts; Sent), "Views" with "+ Create view" link, then workspace group "SaaSUI" (workspace name, caret) > "Shared inboxes" > Demo Inbox (pink dot), My Inbox (gray dot). Inbox colors are shown as small dots. Selected row: darker gray rounded fill. Row height ~28px; indent 16-18px per level.
3. **Middle list pane** (~280px) with tab strip above both panes.
4. **Right plugin rail** (~58px, white): vertical icon+caption stack: Help & tips, Calendar, Contacts, Shortcuts, then a divider and "Manage" (blue grid icon). Clicking a plugin opens a ~260px right side panel; "Manage" opens a panel with search, a dismissible blue tip card, "Find more plugins" card and "Manage sidebar" pin toggles (pin icon per plugin card).

Contextual second sidebars per app: Analytics has its own left list under a workspace switcher dropdown: Overview, Team Performance, Conversations, Tags, Message Templates, SLAs, Customer Satisfaction, then a "Support" group (Glossary, Help). Settings (gear) has a segmented toggle "Company | Personal" at the top (pill, dark navy selected) and a left tree: Admin home, Developers, then workspace "SaaSUI" (collapsible) with Workspaces, Teammates, Inboxes, Rules, Custom fields, Message templates, Signatures, Views, Tags, Roles & Permissions, Imports, App store, Preferences, Billing, Deliverability. Settings pages share a "search teammates, inboxes, rules, tags, and more" bar (~530px) under the top bar.

Workspace switcher: dropdown row at the top of Analytics sidebar and a collapsible workspace node in Settings. Breadcrumbs: small gray "Inboxes >" or "Inbox creation > Workflows library" above a page H1; "< Back to Teammates" link pattern on sub-pages. No command palette seen in screenshots (Front has a "Shortcuts" plugin and keyboard shortcuts panel).

Concept model (from help 2137): channel (email address, SMS number, chat...) connects to exactly one inbox; an inbox is an organizational container holding 0..n channels; "empty inboxes" hold conversations moved by rules. Rules move/assign conversations between inboxes.

## 3. Visual language

- **Palette** (est.): chrome navy #0A1A33 (top bar); sidebar/list background cool light gray #F2F3F7; content cards white #FFFFFF; primary blue ~#2F6FEB (buttons, links, selection in message list ~#2563EB fill with white text); text near-black #1A1A1A, secondary gray #6B7280; tag/status accents: pink (Demo Inbox dot), green (progress), red for errors (#D93025-ish text, "Could not find teammate to clone"), purple for rule icons (#7C3AED on pale lavender circle), orange on pale peach for SLA, light-blue circle for assign. Marketing site (measured visually): deep aubergine #340B3F-ish hero with lime announcement bar (#EEFA90-ish) and lavender chat widget; logo "F" glyph in purple.
- **Light only** in the app screenshots; the saasui site itself has a dark toggle. Front dark mode not observed.
- **Typography**: clean grotesque sans, looks like Inter (UI) at 13-14px body in lists/sidebars, 15px message body, page H1 ("Message templates", "Admin home") ~26px bold (700), H2 section titles ("Learn how to...") ~22px bold, card titles ~16-17px semibold, helper text 13px gray. Help center body font is a custom font stack with system fallback, H1 24px/800 (measured). Marketing hero ~64px, weight 500-600, tight tracking.
- **Spacing/density**: medium-comfortable. Sidebar rows ~28px, message list rows ~84px (sender + date, subject, preview = 3 lines), table rows in settings ~56px (two-line cells: bold name + gray description), card padding ~20px, card grid gap ~20px.
- **Radii**: 8px on cards/rows, 12px on larger cards and modals, fully round (999px) on primary action buttons ("Add a template", "Add a rule", "Invite"), pill search bars, toggle, avatars circular.
- **Borders vs shadows**: cards = 1px very light border plus soft diffuse shadow (0 1px 4px rgba(0,0,0,.08) est.); tables are borderless with a single hairline under the header; sidebar separated from content by a 1px line only.
- **Iconography**: thin 1.5px outline icons, monochrome gray in nav; colorful filled circular icon badges (32-40px, pale tinted background + saturated glyph) for rule types, channels, plugins. Emoji used in tags (bug, party popper, sunglasses, red exclamation) and in email body.
- **Illustration**: friendly line-art character (woman at laptop) on a pastel mint-to-yellow gradient for "Front Academy"; an abstract gradient hero (mint, sky, pink, yellow, 3D blobs, Front "F" mark) on the App store; no heavy illustration elsewhere.

## 6. Interaction patterns

- **Onboarding**: persistent "Setup guide" control in the top bar with mini progress underline; opens a 3-step checklist popover; empty inbox offers direct connect buttons; wizard-style stepper for creating inboxes; "Continue without ..." skip buttons at every optional step; Front Academy training link.
- **Contextual help**: dismissible info cards beside every settings table; (i) icon at top right to reopen; "Help & tips" and "Shortcuts" plugins in the right rail (keyboard shortcut cheat sheet).
- **Progressive disclosure**: "More options" in When/If/Then blocks; "More filters" in analytics; "Show more" on admin home; collapsible sidebar groups with caret; "Smart rules" gated with badges.
- **Safety**: Unsaved-changes modal when navigating away; "Create rule" disabled until required fields done; per-cell inline errors in bulk upload; rule "Stop processing other rules" checkbox; "Rule insights" shows blast radius (conversations affected).
- **Hover/status**: hovered nav link shows target URL in the browser status bar (saw `app.frontapp.com/inboxes/teams/folders/.../unassigned`); active list item highlighted solid blue; unread blue dot.
- **Real-time**: analytics "Progress: 5%" spinner while backfilling; skeleton loaders on lists.
- **Drag/drop**: "Prioritize your plugins" tip says plugins can be reordered by dragging; pin icon toggles sidebar presence.
- **Inline editing**: not observed in tables (rows navigate to detail pages); inline dropdown chips inside the rule sentence are the main inline-edit pattern.

## 8. Ideas worth borrowing for rightnow-ai

- Use a dark-navy slim top bar with icon-only app switcher (Inbox / Campaigns / Leads / Analytics / ...) and a central scoped search pill; sidebar stays light gray so content cards pop. Keeps global nav tiny and frees sidebar for context (mailbox/inbox folders).
- Inbox: 3-pane layout with tab strip (Unassigned/Assigned/Archived/Snoozed...) mapped to cold-email states (Interested / Replied / Out of office / Bounced / Unsubscribed / Archived); list cards with unread dot, solid-blue selected row, 3-line density; conversation header with Assign + Archive + Snooze; "Reply" pill inside the message card; internal comment box at bottom for notes.
- Right-hand plugin rail with a Manage panel: put lead details/CRM, campaign context, and mailbox health as collapsible side panels instead of separate pages.
- "Setup guide" progress control in the top bar plus a 3-step checklist popover: Connect mailbox > Start warm-up > Launch first campaign. Show "0/3" with a thin green bar.
- Connect-mailbox wizard with a numbered mini-stepper and tile pickers (Google / Microsoft / Other IMAP-SMTP), skip buttons ("Continue without ...") and sticky footer actions.
- Automations builder as When / If / Then stacked row-cards with inline dropdown chips, "+ AND / + OR" links, "Rule is active" toggle, "Stop processing other rules" checkbox and a "Rule insights" blast-radius card ("Affects N leads/campaigns"). Fits reply-handling rules (if reply is OOO -> pause, if interested -> move to pipeline).
- Settings tables: icon badge + bold name + gray description first column, DEFAULT micro-chip, "Available in" column, right-side dismissible explainer card ("Learn more ↗"). Reuse for Templates, Tags, Custom fields, Mailboxes.
- Bulk CSV upload preview table with per-cell red inline errors before commit (leads import).
- Analytics: one filter bar (date range with prev/next arrows, inbox/mailbox filter, "More filters"), "Main Metrics" 4-card strip, "Changes Over Time" line with metric selector and "Compare to previous period", export icon on every chart, saved "views" as tabs with "+ Add view", skeleton cards while loading.
- Settings shell with "Company | Personal" segmented toggle at the top of the settings tree (maps to Workspace vs My settings).
- Badge system: tiny uppercase gray DEFAULT chips and teal/amber feature badges; unsaved-changes modal copy and layout; fully-rounded primary buttons paired with outlined secondary pills.

## 9. Why it works

Front looks polished because it commits to a small, disciplined kit: a dark navy bar that frames the app, a cool light-gray sidebar, white rounded cards with barely-there borders and soft shadows, one confident blue for every primary action, and generous 8-12px radii with pill-shaped buttons that make it feel friendly rather than enterprise-gray. Density is calibrated: the message list is three clean lines per item with a single bold sender and muted metadata, so the selected blue row is instantly findable, and settings tables use a two-line first cell (bold name + gray description) so every row explains itself without extra columns. It is clearly presented because each screen has one H1, one primary pill button at the top right, and a contextual explainer card that says in a sentence what the object is and links to docs; wizards break big tasks (create an inbox, build a rule) into numbered steps with skip buttons, and the rule builder reads as a sentence ("When... If... Then...") so non-technical users can follow it. Users understand what the software is for within seconds because the home/empty states and the setup guide state the job directly (connect your work email, add a shared inbox, create rules, invite your team), the sidebar is organized around the real objects (inboxes, rules, tags, templates, analytics), and collaboration affordances (Assign, comments with @, Archive) sit exactly where the work happens, in the conversation header. Limits worth noting: the screenshots are loading/empty-state heavy (analytics skeletons, empty inbox), so real data styling and keyboard/dark-mode behavior were not observed.
