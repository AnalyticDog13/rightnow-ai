# Landing page design references (15)

Homepages were fetched and loaded on 2026-10-30. Extra URLs marked (unchecked) were not fetched. appflowy.com is chosen separately and excluded. Linear was dropped because its page is client-rendered and returned only "Loading...".

1. **Attio** - https://attio.com
   Extra: https://attio.com/help (unchecked)
   Category: sales-email SaaS (CRM)
   Why: Polished CRM hero with a product demo built from realistic UI (meeting transcript plus chat). A good model for presenting the rightnow CRM and inbox without a paid-plan funnel.

2. **Firecrawl** - https://www.firecrawl.dev
   Extra: https://docs.firecrawl.dev/contributing/self-host
   Category: dev tool (open source, self-hostable)
   Why: Interactive playground on the page and a short Docker Compose self-host guide linked from it. Shows how to put "try it / run it yourself" front and centre.

3. **Superhuman** - https://superhuman.com
   Extra: https://superhuman.com/blog (unchecked)
   Category: sales-email SaaS (email client)
   Why: Benchmark for email-product polish: looping video demo hero, tight copy, and speed-focused positioning. Useful for the unified-inbox section.

4. **Instantly.ai** - https://instantly.ai
   Extra: https://instantly.ai/blog (unchecked)
   Category: sales-email SaaS (the product being replaced)
   Why: Feature-for-feature parity reference (warm-up, campaigns, inbox, analytics), testimonial layout and SEO structure. Study it to mirror the section order and then differentiate on open source and self-hosting.

5. **Twenty** - https://twenty.com
   Extra: https://docs.twenty.com/developers/self-host/capabilities/docker-compose
   Category: open-source self-host (CRM)
   Why: Closest category peer: an open-source CRM that leans on its "#1 open source CRM on GitHub" claim. Its Docker Compose guide covers install, config, backups and troubleshooting.

6. **Cal.com** - https://cal.com
   Extra: https://cal.com/docs/self-hosting/installation (redirects to https://cal.diy/installation)
   Category: open-source self-host
   Why: Open-source scheduling with a clear self-hosted entry in the nav and a repo link. Shows how to balance a hosted funnel with a self-host path.

7. **Plausible Analytics** - https://plausible.io
   Extra: https://plausible.io/docs/self-hosting
   Category: open-source self-host
   Why: Minimal, fast page with a live demo button and strong SEO. Its self-hosting docs are an example of a clear deploy path.

8. **PostHog** - https://posthog.com
   Extra: https://posthog.com/docs/self-host
   Category: open-source self-host / dev tool
   Why: Distinctive brand voice and light/dark theming, with a hobby deploy script and self-host guide covering requirements, config and upgrades.

9. **n8n** - https://n8n.io
   Extra: https://docs.n8n.io/hosting/
   Category: open-source self-host (automation)
   Why: Visual workflow imagery that suits rightnow's automations and sequence builder. Self-host-in-Docker is stated up front, with a hosting overview doc behind it.

10. **Dub** - https://dub.co
    Extra: https://dub.co/docs (unchecked)
    Category: open-source dev tool (links and attribution)
    Why: Modern, product-led visuals for an analytics-heavy tool, with an open-source GitHub link. Good for the analytics section.

11. **Resend** - https://resend.com
    Extra: https://resend.com/docs/introduction (unchecked)
    Category: sales-email SaaS / dev tool (email API)
    Why: Developer-grade email positioning with terse copy and docs that begin at "how to use it". A tone reference for the rightnow how-to-use pages.

12. **Coolify** - https://coolify.io
    Extra: https://coolify.io/docs/get-started/installation
    Category: open-source self-host
    Why: Self-hosting is the product: the hero offers "Self-host for free", with an installation guide covering server requirements and methods. Model for the deploy and requirements section.

13. **Chatwoot** - https://www.chatwoot.com

    Category: open-source self-host (inbox)
